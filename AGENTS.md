# Agent Instructions

This repo is an Astro static site for `sudesh.co.in`.

Start here, then read only the topic files needed for the task:

- `.agents/operating-rules.md` for what agents should and should not do.
- `.agents/project.md` for stack, commands, routes, and repo layout.
- `.agents/design.md` for visual and accessibility expectations.
- `.agents/content.md` for articles, drafts, and NDA-safe writing.
- `.agents/astro.md` for Astro-specific implementation patterns.
- `.agents/forms.md` for the Google Form contact page.
- `.agents/deployment.md` for GitHub Pages, CNAME, DNS, RSS, and sitemap.
- `.agents/verification.md` for the verification harness to run before handoff.

Minimum expectation before finishing code changes:

1. Read `.agents/operating-rules.md`.
2. Read the relevant topic doc.
3. Run the smallest useful verification from `.agents/verification.md`.
4. Report what changed and what was verified.

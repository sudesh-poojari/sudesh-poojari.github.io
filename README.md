# Sudesh Poojari

Personal portfolio and technical writing site for `sudesh.co.in`.

## Stack

- Astro
- TypeScript
- Markdown/MDX content collections
- GitHub Pages deployment

## Local Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

## Content

- Long-form articles live in `src/content/articles`.
- Drafts can be kept by setting `draft: true` in frontmatter.

Before publishing, review each post for NDA safety and avoid employer-specific names, private metrics, screenshots, dashboards, logs, tickets, roadmap details, or internal architecture diagrams.

## Contact Form

The contact page embeds a Google Form. Update `src/pages/contact.astro` if the form URL changes.
